# Get Real

A lightweight, portable web hub featuring:
- 📖 **Jujutsu Kaisen Manga Reader**: All 272 chapters with single-page and continuous reading modes, bookmarks, and instant standalone HTML generator.
- 💬 **Live Chat Room**: Custom chat rooms with optional passwords, host controls (kick/ban), and real-time messaging.
- 📋 **The Board**: Community forum with threaded discussions.
- 📝 **Quick Scratchpad**: Personal notes auto-saved to your active account.
- 👤 **Unified Account System**: Synchronized profiles, Elgatitolover sticker avatars, multi-account manager, and 1-click cross-device sync codes.
- 🌓 **Cohesive Dark & Light Theming**: Fully unified card surfaces and headers.

## Getting Started
Simply double-click `index.html` in any modern web browser (including school Chromebooks). Zero backend installation required!
